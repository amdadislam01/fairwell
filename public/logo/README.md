# Logo Assets

- `npi-logo.svg`: Official vector crest logo for National Polytechnic Institute.
- `npi-logo.png`: PNG version of the logo.

To replace the logo with a custom image:
1. Replace `npi-logo.png` or `npi-logo.svg` in this directory (`public/logo/`).
2. Update `data/farewellContent.ts` if you change the file extension or filename.
